# Exercise - 3D CSS Cube

![demo](docs/demo.gif)

A simple CSS 3D cube experiment.
Made as a small exercise to experiment with CSS 3D transforms, animations and dynamic colors.

A rotating 3D neon cube built with pure HTML, CSS, and JavaScript. It features animated CSS 3D transforms, dynamic glow effects, and multiple switchable color themes.

## Technologies
* HTML
* CSS
* JavaScript
